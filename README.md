# He Lives

[helives.dev](https://helives.dev) is a Scripture-centered site. The home page presents a new King James passage every 60 seconds. Words of Christ are in red. **Explore more** opens the selected passage on Bible Gateway.

Genesis 1–3 is a narrated meditation with JavaScript-driven 2D illustrations. The Scriptures page names the whole Protestant canon. The Faith page introduces the Christian faith and invites readers to follow Christ.

The King James Version is public domain in the United States.

This is not a church, not a sacrament, and not a claim that God endorsed the software.

## Visit

- Home — a new passage every minute
- [The Scriptures](https://helives.dev/scriptures)
- [Genesis](https://helives.dev/genesis)
- [Faith](https://helives.dev/faith)

## Run locally

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:5173/](http://localhost:5173/).

```bash
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```
